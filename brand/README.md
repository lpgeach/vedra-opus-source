# Vedra Opus brand

Luke's logo for Vedra Opus (2026-11-26), drawn as SVG.

| File                        | What                                                           |
| --------------------------- | -------------------------------------------------------------- |
| `vedra-opus-logo-dark.svg`  | The full logo, the VO mark above "Vedra Opus", in black        |
| `vedra-opus-logo-light.svg` | The same in white, for dark backgrounds                        |
| `vedra-opus-mark-dark.svg`  | The VO mark alone, in black                                    |
| `vedra-opus-mark-light.svg` | The VO mark alone, in white                                    |
| `vedra-opus-icon.svg`       | The app icon: the white mark on a black square, round-cornered |

- **Typeface:** Outfit (SIL Open Font License; `docs/licences.md`). "Vedra" is Bold (700), "Opus" Regular (400). In the logo files the letters are outlines, so they need no font installed.
- **The app icon** is `apps/desktop/icons/icon.png`, `vedra-opus-icon.svg` drawn at 1024 × 1024. Packaging makes each system's sizes from it.
- **In the app:** the Welcome screen shows `vedra-opus-logo-dark.svg` as a mask in the theme's text colour, so one file serves both themes.
