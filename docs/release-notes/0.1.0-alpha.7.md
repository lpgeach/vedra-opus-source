## 🎬 Vedra Opus 0.1.0 alpha 7

[![Sponsor Vedra Opus](https://img.shields.io/badge/Sponsor-Vedra%20Opus-db61a2?style=for-the-badge&logo=githubsponsors&logoColor=white)](https://github.com/sponsors/lpgeach) [![ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/lukegeach)

**Help and feedback are one click away.** Everything in alpha 6, plus:

- **A Feedback button** at the top of the window, beside Donate. It opens the feedback page in your browser, with the app's version and your computer's system filled in. Nothing is sent until you send it from that page.
- **Help → Vedra Opus Help**, in the menu (☰), opens [the help](https://github.com/lpgeach/vedra-opus-releases/blob/main/help/README.md) in your browser. You need to be online.
- **New pictures in the help,** and the one for a video's settings now shows a video.

### ⬇️ Windows 10 or 11 (64-bit)

1. Download **`Vedra-Opus-0.1.0-alpha.7-x64.exe`** below.
2. Run it. The alpha is **not signed** yet, so Windows shows "Windows protected your PC": choose **More info → Run anyway**.
3. Choose where to install it, and start Vedra Opus from the Start menu.

Already on alpha 4, 5 or 6? **Help → Check for Updates** finds this version.

SHA-256: `@EXE@`

### ⬇️ macOS 11 or later

1. Download the one for your Mac:
   - **Apple Silicon** (M1 and later): **`Vedra-Opus-0.1.0-alpha.7-arm64.dmg`**
   - **Intel**: **`Vedra-Opus-0.1.0-alpha.7-x64.dmg`**
   - Not sure? Apple menu → About This Mac: "Chip: Apple M…" is Apple Silicon; "Processor: Intel" is Intel.
2. Open it and drag **Vedra Opus** into **Applications**.
3. The alpha is **not notarised by Apple** yet, so the first time macOS will not open it. Try opening it once, then go to **System Settings → Privacy & Security** and choose **Open Anyway** beside Vedra Opus.

SHA-256:

- Apple Silicon: `@ARM@`
- Intel: `@X64DMG@`

### ⬇️ Linux (64-bit)

- **AppImage**, for most distributions: download **`Vedra-Opus-0.1.0-alpha.7-x86_64.AppImage`**, make it executable (`chmod +x Vedra-Opus-0.1.0-alpha.7-x86_64.AppImage`) and run it. If it does not start, install FUSE 2 (on Ubuntu 24.04: `sudo apt install libfuse2t64`).
- **Debian or Ubuntu package:** download **`Vedra-Opus-0.1.0-alpha.7-amd64.deb`**, then `sudo apt install ./Vedra-Opus-0.1.0-alpha.7-amd64.deb`.

Already using the alpha 5 or 6 AppImage? **Help → Check for Updates** finds this version.

For text-to-speech on Linux, install espeak-ng (`sudo apt install espeak-ng`). Everything else works without it.

SHA-256:

- AppImage: `@APPIMAGE@`
- .deb: `@DEB@`

### ⚠️ Good to know

- **This is an alpha:** keep copies of projects you care about.
- **Projects** from alpha 5 and 6 open in alpha 7, and the other way round: the project format has not changed.
- **Updates:** **Help → Check for Updates** finds new versions here on Windows (from alpha 4) and in the Linux AppImage (from alpha 5). On macOS and with the .deb, download new versions from [this page](https://github.com/lpgeach/vedra-opus-releases/releases).
- **Every installer here was built and tested automatically** on its own system, the Apple Silicon one on an Apple Silicon Mac.
- **The Linux version** was built and tested on a current Ubuntu. Much older distributions may not run it.
