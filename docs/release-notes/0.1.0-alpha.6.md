## 🎬 Vedra Opus 0.1.0 alpha 6

[![Sponsor Vedra Opus](https://img.shields.io/badge/Sponsor-Vedra%20Opus-db61a2?style=for-the-badge&logo=githubsponsors&logoColor=white)](https://github.com/sponsors/lpgeach) [![ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/lukegeach)

**Transitions and animations you can see before you choose them, and a help guide to every feature.** Everything in alpha 5, plus:

- **The Transitions tab is a gallery:** None, Fade, Push, Cover, Uncover, Wipe, Split, Iris and Zoom, each a small picture of two slides. Point at one to watch it play; click it to choose it. Effect Options, the duration and Apply to All Slides sit beside it. While you edit a layer, the tab sets that layer's transition.

  ![The Transitions tab](https://github.com/lpgeach/vedra-opus-releases/raw/main/help/images/ribbon-transitions.png)

- **The Animations tab has galleries too:** Entrance and Exit each show their effect as a picture. Click one for a grid of all twelve effects, each playing as you point at it. Motion paths show a drawing of each kind.

  ![The grid of entrance effects](https://github.com/lpgeach/vedra-opus-releases/raw/main/help/images/entrance-gallery.png)

- Every picture moves exactly as your course will. If your computer asks for less motion, they stay still.
- **Help for every feature:** [the Vedra Opus help](https://github.com/lpgeach/vedra-opus-releases/blob/main/help/README.md), sixteen pages with pictures from the app, from getting started to publishing for an LMS.

### ⬇️ Windows 10 or 11 (64-bit)

1. Download **`Vedra-Opus-0.1.0-alpha.6-x64.exe`** below.
2. Run it. The alpha is **not signed** yet, so Windows shows "Windows protected your PC": choose **More info → Run anyway**.
3. Choose where to install it, and start Vedra Opus from the Start menu.

Already on alpha 4 or 5? **Help → Check for Updates** finds this version.

SHA-256: `22935c381eed2cc41fd5faa82ec54b33d451e382abbad92ca0dcfa3afba29779`

### ⬇️ macOS 11 or later

1. Download the one for your Mac:
   - **Apple Silicon** (M1 and later): **`Vedra-Opus-0.1.0-alpha.6-arm64.dmg`**
   - **Intel**: **`Vedra-Opus-0.1.0-alpha.6-x64.dmg`**
   - Not sure? Apple menu → About This Mac: "Chip: Apple M…" is Apple Silicon; "Processor: Intel" is Intel.
2. Open it and drag **Vedra Opus** into **Applications**.
3. The alpha is **not notarised by Apple** yet, so the first time macOS will not open it. Try opening it once, then go to **System Settings → Privacy & Security** and choose **Open Anyway** beside Vedra Opus.

- Apple Silicon: `ee09748cd74e05b3541a9b72a996efe09652df8c9d3e6f108471641953e6871f`
- Intel: `6bd5dec4915676df829d0a2eef1f10e5523b7aef5055255e9862609243225f55`

### ⬇️ Linux (64-bit)

- **AppImage**, for most distributions: download **`Vedra-Opus-0.1.0-alpha.6-x86_64.AppImage`**, make it executable (`chmod +x Vedra-Opus-0.1.0-alpha.6-x86_64.AppImage`) and run it. If it does not start, install FUSE 2 (on Ubuntu 24.04: `sudo apt install libfuse2t64`).
- **Debian or Ubuntu package:** download **`Vedra-Opus-0.1.0-alpha.6-amd64.deb`**, then `sudo apt install ./Vedra-Opus-0.1.0-alpha.6-amd64.deb`.

Already using the alpha 5 AppImage? **Help → Check for Updates** finds this version.

For text-to-speech on Linux, install espeak-ng (`sudo apt install espeak-ng`). Everything else works without it.

SHA-256:

- AppImage: `d790e6aa9cb4d39c853276b4195b62445c2c159764b894483a97a3310a1002c9`
- .deb: `97c1be4925e0591b096928aab9beeb5b547826e6b1f116880a519b14a6d322fe`

### ⚠️ Good to know

- **This is an alpha:** keep copies of projects you care about.
- **Projects** from alpha 5 open in alpha 6, and the other way round: the project format has not changed.
- **Updates:** **Help → Check for Updates** finds new versions here on Windows (from alpha 4) and in the Linux AppImage (from alpha 5). On macOS and with the .deb, download new versions from [this page](https://github.com/lpgeach/vedra-opus-releases/releases).
- **Every installer here was built and tested automatically** on its own system, the Apple Silicon one on an Apple Silicon Mac.
- **The Linux version** was built and tested on a current Ubuntu. Much older distributions may not run it.
