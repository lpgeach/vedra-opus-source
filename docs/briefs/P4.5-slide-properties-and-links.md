# P4.5 Slide properties and Overview links

**Work package:** P4.5, needs P4.3 (done). **Status:** implemented on branch `wp/p4.5-slide-properties`.

## Saved format version 3

`slide.properties.controls: { previous: boolean; next: boolean }`: which of the player's own buttons the slide shows. Migration 2→3 sets both to true (what every slide did before). Frozen fixture `fixtures/legacy/v2-states-and-triggers`; current fixtures updated. Only the buttons the player has today are included; seekbar and menu are added with the player frame (P8.1), so no switch exists that does nothing.

## Decisions

- **Command** `slide.setProperties` (advance, revisit, controls; parts left out stay).
- **Editor:** with nothing selected, the Format panel shows the slide's properties: Moves on (when the learner chooses / by itself when its timeline ends), When revisited (decide automatically / start again / carry on), and the Previous and Next buttons.
- **Engine and player:** the view carries `controls`; the player hides a button the slide does not show, and its arrow and Page keys do nothing then. Triggers can still navigate.
- **Links** (`slideLinks`, `unreachableSlides` in the model): every way between slides: enabled triggers' jumps (including next/previous jumps and "otherwise" actions), the slide's Previous and Next buttons when shown, and auto-advance. A slide is unreachable when nothing leads to it from the first slide.
- **Overview:** arrows for trigger jumps (only: Next/Previous links between every neighbour would hide them), drawn over the cards and re-measured when the Overview resizes; "Show links between slides" toggles them. Unreachable slides get a "Not reachable" tag and a dashed outline.
