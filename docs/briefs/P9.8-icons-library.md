# P9.8 Icons and illustrations library

**Work package:** P9.8. It needs P9.7 (PR #76).

**Plan line:** an icons and illustrations library using an openly licensed icon set, with a searchable insert dialog.

**Luke's decisions (session 71):**

- **Icons:** Lucide, ISC licence.
- **Illustrations:** a CC0 set.

**My design choices** (Luke asked to go through all of Phase 9), listed for him to change:

1. **The sets:**
   - **Lucide:** `lucide-static` 1.77.0, 2,098 icons.
   - **Open Doodles** by Pablo Stanley: 33 drawings of people, CC0 (opendoodles.com says so).
     - They come from the npm package `react-open-doodles` 1.0.5, whose own code is MIT.
     - Each drawing has two colours, "ink" and "accent", which the author can change.
2. **Nothing is installed from npm, and no code from either package runs.**
   - `scripts/build-library.mjs` downloads the two pinned tarballs and checks each against the registry's SHA-512.
   - It turns the drawings into plain data and writes it to `apps/desktop/src/renderer/library/`:
     - Lucide's from its JSON files;
     - the doodles' by parsing their code with the TypeScript parser, without running it.
   - The output and the two licences (`apps/desktop/resources/licences/`) are committed.
   - The script is only run again to change a version. No npm dependency is added: the doodles package's old React peer range would have changed the lockfile.
3. **An inserted icon or illustration is a new `graphic` object, which holds its own drawing.**
   - The project, and the published course, never depend on the library or its version.
   - The drawing is a tree of plain SVG shapes: `g`, `path`, `circle`, `ellipse`, `rect`, `line`, `polyline` and `polygon`.
   - Their attributes come from a fixed list, and each value has a strict pattern: numbers, path data, transforms. There is no `url(…)`, no script, no style and no links.
   - Its colours are named: the paint `ink` or `accent` is drawn in the object's `ink` or `accent` colour, which can be a theme colour. Otherwise a paint is `none` or a fixed colour.
   - A Lucide icon also has a stroke width.
4. **Drawn as an inline SVG** in the object's frame, keeping its proportions (`xMidYMid meet`).
   - The accessible name is the object's alt text. It starts as the item's name ("Heart icon", "Reading illustration").
   - A graphic marked decorative is hidden from screen readers, as pictures are.
5. **The dialog:** Insert → **Icons…** has two tabs, Icons and Illustrations, and a search box.
   - The search matches names and Lucide's tags. Each word must match.
   - It shows up to 240 results at a time, and says how many there are.
   - The library loads only when the dialog first opens, so it does not slow the app's start.
6. **The Format panel's Graphic section:**
   - the ink colour, and for illustrations the accent colour, each a theme or fixed colour;
   - for icons, the line width.
7. **Licences:** the app ships both notices. `docs/licences.md` records both sets.
   - **Luke decided (session 76):** a published course that uses Lucide icons carries Lucide's notice. It is in `THIRD-PARTY-NOTICES.txt` beside `index.html`, with Open Doodles' credit when it uses those. Publishing without a needed notice fails.

## Saved format version 32

- **A new object type `graphic`**, whose props are:
  - `library` (`lucide` or `openDoodles`) and `key`;
  - `viewBox { width, height }`;
  - `nodes` (at most 5,000 in all);
  - `ink`, `accent`, `strokeWidth` (a number from 0.25 to 6, or null).
- **Migration 31 → 32:** nothing changes. Legacy fixture `v31-two-slides`.

## Done when

- **Model:**
  - the schema accepts every item in both libraries;
  - it refuses other elements, attributes, `url(…)`, script and event attributes;
  - the node limit holds;
  - a migration and fixture;
  - the property test inserts graphics.
- **Render:**
  - the shapes, the colours (theme and fixed), the stroke width and the proportions;
  - the accessible name, and decorative graphics;
  - a visual reference.
- **Library:** the data's tests:
  - counts;
  - each item passes the schema;
  - search by name and tag;
  - the licences are present.
- **e2e:**
  - search and insert an icon and an illustration;
  - change their colours;
  - save and reopen;
  - publish, and they are drawn in the course.
