# P9.9 Tables

**Work package:** P9.9. It needs P9.8 (PR #77).

**Plan line:** tables.

**My design choices** (Luke asked to go through all of Phase 9), listed for him to change:

1. **A table is one object, a grid of cells.**
   - Each cell holds rich text, the same text as a text box's: fonts, sizes, colours, lists, `%Variable%`.
   - A cell may have its own fill.
   - There are no merged cells in this package.
2. **Columns and rows are shares** of the table's frame, so resizing the table scales the grid. A new table's are equal.
   - The Format panel takes column shares as numbers ("1, 2, 1").
   - Rows stay equal unless the author sets their shares too.
3. **Its look:**
   - an optional header row and header column, in a header fill with their own text colour (by default the first accent colour, and the background colour on it);
   - optional banded rows;
   - a border colour and width;
   - cell padding.

   Theme colours throughout, so a theme change restyles it.

4. **In a course it is a real HTML table:** `th` with `scope` for headers, `td` for the rest.
   - Its accessible name is its alt text, if it has one.
   - Screen readers can move by row and column.
5. **Editing in the editor:**
   - double-click a cell to edit its text, with the same editor as text boxes (Escape or a click elsewhere commits it, one undo step);
   - the Format panel's **Table** section picks a row and a column, then inserts above, below, left or right, deletes the row or column, and sets that cell's fill;
   - it also has the header, banding, border, padding and column-share settings.
6. **Not in this package:**
   - Tab moving from cell to cell while editing;
   - pasting a table from elsewhere;
   - sorting;
   - merged cells.

## Saved format version 33

- **A new object type `table`**, whose props are:
  - `columns: number[]` (shares, 1 to 20);
  - `rows: { height, cells: { text, fill }[] }[]` (1 to 100 rows, each with one cell per column);
  - `headerRow`, `headerColumn`, `headerFill`, `headerText`, `bandFill` (null for none), `borderColor`, `borderWidth` (0 to 8) and `padding` (0 to 40).
- **Validation:** every row has as many cells as there are columns.
- `forEachRichText` visits every cell, so renaming a variable rewrites `%Name%` in tables too.
- **Migration 32 → 33:** nothing changes. Legacy fixture `v32-two-slides`.
- **Pure helpers in the model:** insert and delete a row or column, and set column shares. They are tested there, and the editor uses them.
