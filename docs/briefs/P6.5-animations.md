# P6.5 Animations

**Work package:** P6.5, needs P3.1 (engine), P3.2 (player) and P4.3 (triggers), all done.

**Plan line:** entrance and exit effects (fade, fly, float, wipe, grow, spin, and the rest of a standard set) with duration, direction, and by-paragraph sequencing for text. Motion paths (line, arc, freeform, relative start) with the `move along path` action and `animation completes` event. All driven by the engine clock, so scrubbing works.

## Luke's decisions (2026-11-18)

- **Exit timing:** an exit animation _finishes_ as the object's time on the timeline ends; it plays during the last part of its bar. Scrubbing shows it, and it works for objects that last until the timeline ends. Plan §5 is reworded to say so.
- **Motion path clock:** a running path moves with the engine's clock, not the playhead. It pauses while its layer's timeline is paused or the layer is hidden, and carries on after the timeline has ended.
- **By paragraph:** the duration is per paragraph. Paragraphs animate one after another, so 4 paragraphs at 0.5 s take 2 s.
- **Adding a motion path** also adds the trigger "move along path when the timeline starts", which the author can change or delete.

## Saved format version 9

Every object gets `animations`:

```ts
animations: {
  entrance: Effect | null,
  exit: Effect | null,
  motionPaths: MotionPath[],
}
Effect {
  kind: EffectKind,
  duration: number,          // seconds, 0.05–30; by paragraph: per paragraph
  direction: Direction | null,
  byParagraph: boolean,       // only text, shapes with text, and buttons
}
MotionPath {
  id, name,
  shape: 'line' | 'arc' | 'freeform',
  points: Point[],            // stage units, offsets from the object's own position
  duration: number,           // seconds, 0.05–60
  easing: 'linear' | 'easeIn' | 'easeOut' | 'easeInOut',
  relativeStart: boolean,
}
```

### Effects and their directions

Our own set. For an entrance, the direction is where the object comes _from_. An exit is its entrance run backwards, so there the direction is where it goes _to_.

| Kind       | What it does (entrance)                                  | Directions                                                           |
| ---------- | -------------------------------------------------------- | -------------------------------------------------------------------- |
| `fade`     | opacity 0 → 1                                            | none                                                                 |
| `fly`      | comes in from fully off the stage                        | left, right, top, bottom, topLeft, topRight, bottomLeft, bottomRight |
| `float`    | rises a short way (a tenth of the stage) while fading in | left, right, top, bottom                                             |
| `wipe`     | revealed from one side                                   | left, right, top, bottom                                             |
| `split`    | revealed from the middle outwards                        | horizontal, vertical                                                 |
| `iris`     | revealed by a growing circle from the centre             | none                                                                 |
| `grow`     | scales up from nothing                                   | none                                                                 |
| `zoom`     | scales from half size while fading in                    | none                                                                 |
| `spin`     | turns once while fading in                               | clockwise, anticlockwise                                             |
| `spinGrow` | turns once while growing from nothing                    | clockwise, anticlockwise                                             |
| `bounce`   | drops in from above the stage and bounces                | none                                                                 |
| `swivel`   | turns in about its own axis, like a card                 | horizontal, vertical                                                 |

- **Easing:** entrances ease out, so exits ease in. `bounce` has its own keyframes.
- **Validation:** the direction must be one the kind takes (null for the kinds without). The first direction in each list is the default.

### Motion paths

- **Points** are offsets of the object's position, in stage units, from where the object is drawn:
  - `line`: two points, start and end.
  - `arc`: three points, start, _through_ (the curve's middle, which the author drags) and end. It is drawn as the quadratic curve through them.
  - `freeform`: two or more points, a polyline.
- **Speed:** the object moves at a constant speed along the path's length, then the easing is applied.
- **Relative start:**
  - Off: the run starts at the path's first point, wherever the object was.
  - On: the path is laid from where the object is now, so running it again moves it further.

### Triggers

- **New action** `moveAlongPath { object, path }`.
- **New event** `animationCompletes { object, animation }`, where `animation` is `{ kind: 'entrance' }`, `{ kind: 'exit' }` or `{ kind: 'path', path }`.
- **Validation:** the path must belong to the object.

### Where animations may be

- **Superseded by B8 (format 36, `docs/briefs/B8-group-member-animations.md`):** a group's members now have their own timing and animations, and grouping keeps them. What follows is how it was.
- **Top-level objects only.** An object inside a group has none. Grouping drops its members' animations in the same undo step (with a status message), and validation reports any left on a group's children.
- **Groups** themselves can animate.

### Changes elsewhere in the model

- Migration 8 → 9 adds `{ entrance: null, exit: null, motionPaths: [] }` to every object at any depth. Legacy fixture `v8-two-slides`.
- `object.update` takes `animations`, which replaces the whole value.
  - Paths that disappear take with them the triggers that run them or wait for them.
  - An entrance or exit that disappears takes its `animationCompletes` triggers too.
- Duplicating gives paths new ids, and triggers copied with the object follow the new ids.
- Path ids are unique project-wide.

## Runtime (engine)

- **Effect time:** `ObjectView.effect`, `{ phase: 'entrance' | 'exit'; time }` or absent. `time` is seconds into the effect; by paragraph, into the whole sequence.
  - **Entrance** runs over `[start, start + total)` on the playhead.
  - **Exit** runs over `[end − total, end)`, where `end` is the object's end (the timeline's end for `untilEnd`).
  - Where they overlap, the exit wins. `total` is `duration × paragraphs` by paragraph, otherwise `duration`. The engine counts paragraphs from the text document; list items count one each.
  - Because it is computed from the playhead, it pauses, seeks and scrubs with the timeline.
- **Motion:** `ObjectView.offset`, `{ x, y }` in stage units, present when not zero.
  - **The run:** `moveAlongPath` starts a run of that path, replacing any run the object already has. Its time grows with each `tick` while its layer is shown and not paused. It keeps going after the timeline ends.
  - **Seeking forward** counts as time passing for runs, so a path started by "timeline starts" is in the right place when the editor scrubs. A run started during a seek counts from the playhead time of the event that started it. Seeking back leaves runs where they are.
  - **When a run finishes,** the object stays at the path's end.
  - **Slide entry:** a reset slide starts with no offsets. A resumed slide keeps them (`SavedSlide.m`, rounded to whole stage units).
- **`animationComplete` engine events** become `animationCompletes` triggers:
  - an entrance completes when the playhead crosses `start + total`;
  - an exit completes when the playhead crosses the end, just before `objectLeave`;
  - a path completes when its run reaches the end.
- The engine stays pure. Path maths lives in `engine/src/paths.ts` (point at a fraction of the length, easing).

## Drawing (render, player, editor)

- **`packages/render/src/animation.ts`:**
  - **`effectKeyframes(effect, box, bounds, stage, rotation)`** is pure, returning keyframes for WAAPI. `box` is the element's own box and `bounds` the object on the stage.
  - **The keyframes use** `opacity`, `transform` (with the object's own rotation kept inside it) and `clip-path`, with `transform-origin` at the box's centre. Clip shapes are in pixels of the element's box, so a group (drawn as a 0×0 element at the stage's corner) works with its children's bounds.
  - **`createAnimator()`** keeps one paused `Animation` per element and phase, and sets its `currentTime` from the engine's time on every frame. The browser never runs the clock. By paragraph, each top-level paragraph and list item gets its own animation, delayed by its turn.
  - **Motion** is not a WAAPI animation. The engine computes the offset, because it needs it for resume and later for intersection events. The animator sets the `translate` property, which applies outside `transform`, so it stays on the stage's axes and adds to fly and float.
- **Player:** runs the animator on every frame, for the objects drawn. Redrawing an object in another state keeps its element, and so its animations.
- **Editor stage:** while the timeline plays or is scrubbed (`timelinePreview`), it gets each object's effect and offset from the same engine call (`visibleAt` becomes `previewAt`) and runs the same animator through refs.

## Editor UI

- **Animations ribbon tab,** for one selected top-level object; otherwise its controls are disabled with a hint:
  - **Entrance** and **Exit:** effect (None or a kind), direction (the kind's own), duration, and _By paragraph_ where the object has text.
  - **Motion paths:**
    - Add Line, Add Arc, Add Freeform.
    - A list of the object's paths, choosing which one is edited, with duration, easing, _Relative start_ and Delete.
    - Adding a path adds its "when the timeline starts" trigger, in one undo step.
- **On the stage:**
  - the selected object's paths are drawn, the chosen one with handles: line ends; arc start, middle and end; freeform points. Dragging a handle edits it, as one undo step.
  - **Add Freeform** waits for the author to draw on the stage (press, drag, release). The drawing is simplified to at most 50 points. Escape cancels.
- **Timeline:** an object's bar shades its entrance at the start and its exit at the end.
- **Trigger wizard:** the "Move along path" action (object, then path) and the "animation completes" event (object, then entrance, exit or a path). Both have sentences in `describe.ts`.
- **Undo:** every change is one `object.update` (plus trigger commands for the default trigger), so undo and redo work.

## Not in this package

- Emphasis effects.
- Several effects on one object at once, other than an entrance, an exit and paths.
- Orienting an object along its path, and reversed paths.
- Animation of objects inside groups.
- Slide transitions (P6.6).
- Sound effects on animations.
- Importing PowerPoint animations (P11.1).
