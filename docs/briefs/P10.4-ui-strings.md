# P10.4 The editor's string catalogue

**Plan:** "Editor UI localisation scaffolding (string catalogue; English only at first)."

The editor's own words (menus, ribbon, panels, dialogs) are written in its code today: about 550 in 40 components, and 27 in the application menu. This package builds what lets them be translated later. It moves the surfaces every author sees first, and it sets the rule for the rest. It does not translate the editor into any language, and it does not move all 550 strings at once. The course's own words (the player) are P8.3's and P10.3's, and are not touched.

## The catalogue

- **`apps/desktop/src/shared/strings/en.ts`:** the English catalogue, one flat object of keys to words, `as const`.
  - Keys are dotted by place: `menu.file.save`, `ribbon.tab.insert`, `topBar.publish`.
  - Words may hold `{name}` placeholders.
  - An `&` in a menu label marks its access key, as Electron reads it.
- **`apps/desktop/src/shared/strings/index.ts`:**
  - `StringKey`, the type of every key, so a misspelt key is a type error;
  - `t(key, values?)`, the words in the current language, falling back to English for any key a language lacks;
  - `setLocale(tag)` and `locale()`.

  It is plain TypeScript with no Node or DOM, so main (the menu) and the renderer share it.

- **Languages:** English only. The catalogue type allows others as `Partial` sets, so a translation can be added key by key later.

## The pseudo-locale

- `qps-ploc` is made from English at run time. It wraps each string in `⟦…⟧` and lengthens it by a third with accented vowels, as pseudo-localisation does: `⟦Sävé ·⟧`, `⟦Pröjéct Répösïtöry · · ·⟧`.
- It shows at a glance which words are not yet in the catalogue, and which layouts break when the words get longer.
- It is turned on with the environment variable `VEDRAOPUS_UI_LOCALE=qps-ploc`. Main reads it, sets its own locale, and passes it to the renderer through `app.getInfo` (a field added to `AppInfo`). There is no setting in the app, since English is the only language.

## What moves now

- the application menu (`main/menu.ts`);
- the ribbon's tabs, its group names, and the Home and Insert tabs' commands;
- the top bar (Undo, Redo, the title's label, Publish, the views);
- the Welcome screen;
- the right panel's tab names.

Everything else stays as it is for now. `docs/development.md` gains "Adding words to the editor": **new or changed editor text goes through `t()`**, and moving the rest is done as surfaces are touched.

## Done when

- **Unit tests:**
  - `t` fills placeholders and falls back to English;
  - the pseudo-locale wraps, lengthens and keeps placeholders and access keys working;
  - every `t('…')` key written in the desktop sources exists in the catalogue (a scan of the sources, so a key in an untyped place is caught too);
  - and every key in the catalogue is used.
- **e2e:** the app started with `VEDRAOPUS_UI_LOCALE=qps-ploc` shows the pseudo words in the application menu, the ribbon's tabs, the top bar and the Welcome screen, and still works (a new project opens).
