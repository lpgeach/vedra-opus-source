# P6.8 Text-to-speech

**Work package:** P6.8, needs P6.1 (audio) and P6.3 (media pipeline), both done. Plan line: pluggable provider interface; ships with OS voices only. Cloud voices are an opt-in later decision.

## Luke's decisions (2026-11-18)

- **Linux:** use **espeak-ng** when the system has it, run as a separate program (GPL-3.0, not linked or shipped). Nothing is bundled. Without it, the feature says that no voices are installed and how to get some.
- **macOS and Windows:** use the system's own voices: `say` on macOS, SAPI (`System.Speech`, through PowerShell) on Windows. These are written now and checked in December, with the other Windows and macOS work.
- **Testing:** espeak-ng was installed on Luke's machine for the real-speech tests.

## Providers (main process, `src/main/speech/`)

```ts
interface SpeechProvider {
  id: 'espeak-ng' | 'say' | 'sapi';
  name: string;
  voices(): Promise<SpeechVoice[]>; // { id, name, language }
  speak(text: string, voice: string, rate: number, wavPath: string): Promise<void>;
}
```

- **Choosing one:** `findSpeechProvider(platform)` picks the platform's provider if its program is there (espeak-ng on Linux, found on `PATH`), otherwise null.
  - `VEDRAOPUS_SPEECH=none` hides every provider, so tests can show the "no voices" case.
  - Another provider (Piper, a cloud service) is a new object with the same shape.
- **Text goes in on standard input,** never on the command line, so nothing in it can be read as an option. The programs are run without a shell. At most 5,000 characters.
- **Rate** is a speed from 0.5 to 2 (1 is normal):
  - espeak-ng and `say`: 175 × rate words a minute;
  - SAPI: `round((rate − 1) × 10)`, clamped to −10…10.
- **Voices:**
  - espeak-ng: from `espeak-ng --voices` (the language code is the id, the voice name the name);
  - `say`: from `say -v '?'`;
  - SAPI: from `GetInstalledVoices()`.
  - A voice's id is stored as `<provider>:<voice>`, so a project made on one system says which voice it wanted on another.
- **The result** is a WAV file, which goes through the media pipeline like any import: it becomes an MP3 with its length measured. The asset is named after the first words of the text ("Welcome to the course.mp3").

## IPC

- **`speech:voices` → `{ provider: { id, name } | null; voices: SpeechVoice[]; hint: string | null }`.** The hint, when there is no provider, says how to get one: "No voices are installed. On Linux, install espeak-ng (for example `sudo apt install espeak-ng`, or `sudo pacman -S espeak-ng`), then open this again."
- **`speech:make { text, voice, rate }` → `ImportedAsset`.** The asset is stored in the open project's workspace.
  - Refused with a message when there is no provider, the voice is not one of the provider's, or the text is empty or too long.

## Saved format version 12

- Audio objects get `props.speech: { text, voice, rate } | null`: what the sound was made from, so it can be changed and made again. Recordings and imports have null.
- Validation: text 1–5,000 characters, voice 1–200, rate 0.5–2.
- Migration 11 → 12 sets `speech: null` on every audio object at any depth. Legacy fixture `v11-two-slides`.

## Editor

- **Insert → Text to Speech…** opens a dialog:
  - the text (a text area), with _Use slide notes_ to fill it from the slide's notes;
  - the voice (the provider's voices, with the last one used chosen first);
  - the speed;
  - **Insert**, disabled while there is no text or no voice.
  - Making the sound shows "Making the sound…". The result is inserted like an audio file: on the timeline from 0 s for its length, named "Speech: <first words>", with `props.speech` set. The asset, the object and the timeline growing to fit are one undo step.
  - With no provider, the dialog shows the hint and nothing else.
- **Format tab, for a sound made from text:** **Edit speech…** opens the same dialog filled in, with **Update** instead of Insert.
  - Update makes the sound again and swaps the object's asset, length and speech in one undo step.
  - If the bar's duration was the old length, it becomes the new one; otherwise it is kept.
- **Opened on another system** where the voice is missing, the dialog chooses the provider's first voice and says that the original voice is not available here.

## Done when

- **Model:** the speech schema, migration 11 → 12, the legacy fixture, and the property test setting `props.speech`.
- **Main (unit):**
  - parsing each provider's voice list from a sample of its output (espeak-ng, say, SAPI);
  - each provider's command, arguments and standard input for a request, with the program call faked;
  - rate mapping;
  - provider choice by platform and `VEDRAOPUS_SPEECH`.
- **Main (integration, Linux with espeak-ng):** real voices are listed, and a sentence becomes an MP3 asset with a length that grows with the text.
- **e2e (Linux with espeak-ng):**
  - Text to Speech inserts a sound named after the text, with a waveform and an MP3 asset;
  - _Use slide notes_ fills the text;
  - Edit speech changes the text and remakes the sound (a new asset, the length changed), with undo;
  - save and reopen keep the speech settings;
  - with `VEDRAOPUS_SPEECH=none`, the dialog shows the hint.

## Not in this package

- Cloud voices (Luke decides later).
- Piper or other bundled engines.
- SSML or pronunciation dictionaries.
- Remaking every sound when the text changes elsewhere.
- Speaking while the learner watches (all speech is made into sound files in the editor).
