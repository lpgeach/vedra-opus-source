# P8.6 Resume prompt, restart, exit, and the remaining trigger actions

**Work package:** P8.6, the last of Phase 8. It needs P8.1 to P8.5.

**Plan line:** resume prompt, course restart, exit behaviour, and remaining trigger actions from 4.2 (send email, print, restart).

## What is there already

- **The resume prompt** (P5.1): with `tracking.resume: 'prompt'` and a saved session, the course asks "Continue where you left off?" with Continue and Start over. It has the course's look and words since P8.3.
- **Most of plan §4.2's actions.** "Submit, review, reset and print results" are P7.7's result actions: Submit the question, Review, Retry (which resets the result) and Print results.
- **`startCourse(…).exit()`:** tells the LMS and goes to its return address. It was waiting for this package's "exit course" action.

## Still missing from §4.2

- exit course;
- restart course;
- send email;
- print (the slide);
- open a file;
- set focus;
- seek the timeline.

P8.6 adds them all.

**My design choices** (Luke asked to go through all of Phase 8), listed for him to change:

1. **Restart course** starts the session again, from the first slide, as a fresh start would. It resets:
   - every variable to its default;
   - the slides seen, the slides' memory and every answer;
   - results and timers;
   - draws, which are drawn again.

   It does not reset:
   - **completion:** an LMS cannot take back "completed" or "passed", so a restart never asks it to;
   - the session's elapsed time.

   An open lightbox closes.

2. **Exit course:**
   - In an LMS, the session is saved and committed and the LMS is told the learner left (as when the page closes). With cmi5, the learner goes to the LMS's return address.
   - Otherwise, or when there is no return address, the player tries to close the window.
   - When it may not (a browser only lets a page close a window it opened), the course is replaced by "The course has ended. You can close this page now." It is no longer interactive.
3. **Send email** opens the learner's mail program with a `mailto:` link:
   - the address may be blank, for the learner to fill in;
   - subject and body may use `%Variable%` references, filled in when it is sent;
   - the address may not contain `?`, `&` or `#`, so it cannot add fields of its own.
4. **Print** prints the current slide: the browser's print dialog, with the player's frame hidden by a print stylesheet.
5. **Open a file** opens one of the course's files (the kind the Resources tab takes, P8.2) in a new tab.
6. **Set focus** moves keyboard focus to an object on the slide (for screen readers too). A hidden object is skipped.
7. **Seek timeline** moves a shown layer's playhead to a time, clamped to its length, as the player's seekbar does.

## Saved format version 25

- **New actions:**
  - `restartCourse`;
  - `exitCourse`;
  - `sendEmail { to, subject, body }`;
  - `printSlide`;
  - `openFile { asset }`;
  - `setFocus { object }`;
  - `seekTimeline { layer, time }`.
- **Validation:**
  - `openFile` names an asset of the project of kind `file` or `image`;
  - `setFocus` names an object, and `seekTimeline` a layer, of the trigger's own slide;
  - the email address is checked as above.
- **A new label:** `courseEnded`.
- **Migration 24 → 25:** nothing to change.
- **Legacy fixture:** `v24-two-slides`.

## Runtime

- **Engine:**
  - `restart()`, for the action and the player;
  - the events `exitCourse`, `print`, `openFile { asset }` and `focus { objectId }`;
  - `sendEmail` raises `openUrl` with the `mailto:` link.
- **Player:**
  - on `exitCourse`: `options.onExit` (which `startCourse` gives, to tell the LMS), then the window closes or the end screen shows;
  - on `print`: `window.print()`;
  - on `openFile`: the file's URL in a new tab;
  - on `focus`: the object is focused (made focusable if it is not).

## Editor

The trigger wizard offers each new action:

- Send an email: To, Subject and Body fields;
- Print the slide;
- Restart the course;
- Exit the course;
- Open a file: the course's files and pictures;
- Set focus to: the slide's objects;
- Seek the timeline of: a layer, and a time.

## Done when

- **Model:** validation of each action; migration 24 → 25 and the fixture; the property test adds the new actions.
- **Engine:**
  - restart resets what is listed above and not completion, from the first slide, closing a lightbox;
  - exit, print, open file and focus raise their events;
  - an email's link is built with its variables filled in and encoded;
  - seek moves and clamps.
- **Player browser (Chromium and Firefox):**
  - exit shows the end screen when the window stays open, after `onExit`;
  - restart goes back to slide 1 with the variables reset;
  - send email asks the page to open the `mailto:` link;
  - print calls `print`;
  - open file opens the file's URL;
  - set focus focuses the object.
- **LMS (mock SCORM 2004):** exit commits and terminates the session.
- **e2e:**
  - in the editor, a slide with Restart, Exit and Send email buttons made with the wizard;
  - save and reopen;
  - publish, and use them in the course.

## Not in this package

- Choosing a page to go to on exit, other than the LMS's.
- Printing the whole course (P11.3's handout).
