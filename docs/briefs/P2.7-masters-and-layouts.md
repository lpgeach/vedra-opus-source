# P2.7 Slide masters and layouts

**Work package:** P2.7, needs P2.2 (done). **Status:** implemented on branch `wp/p2.7-masters`.

Plan line: Master View; masters own layouts; slides pick a layout; master objects render beneath slide objects and are not selectable in Slide View; placeholders (title, content). Done when editing a master updates every slide using it, and a fixture with masters round-trips.

## Decisions

- **Format version 2.** A text box gets `props.placeholder: 'title' | 'content' | null`. Migration 1→2 sets it to null on every existing text box; `fixtures/legacy/v1-two-slides` freezes the old shape. New fixture `fixtures/projects/masters`.
- **Layers beneath a slide**, back to front: master layer, layout layer, slide base layer. The layout's placeholders prompt only in Master View; they are not drawn on slides.
- **Placeholders on slides are copies.** Choosing a layout (`slide.setLayout`) adds an empty placeholder text box to the slide for each layout placeholder the slide lacks (fresh ids, same frame). The slide's text is its own; moving a placeholder in the layout later does not move copies already on slides. Objects in the master and layout layers (logos, backgrounds) do update every slide live.
- **Commands:** `master.add/remove/rename`, `layout.add/remove/rename`, `slide.setLayout`. Removing a layout or master turns slides that used it blank (`layoutId` null). Objects in master and layout layers use the ordinary object commands (they already find layers anywhere in the project).
- **Master View** reuses the Stage: `editedSlide` presents the selected master or layout as a stand-in slide whose base layer is that layer, with the master's layer beneath a layout. Left panel lists masters and layouts (add, rename, delete, add placeholder). A project starts with no masters; "Add master" creates one with three layouts (Title and Content, Title Only, Blank).
- **Slide View** gets a Layout picker in the Home tab. Master and layout objects are drawn in a non-interactive underlay and never hit-tested.
- Not in this package: overlay layers (P4.2), feedback masters (P7.5), master triggers, layout thumbnails, theme-per-master, reordering masters or layouts.
