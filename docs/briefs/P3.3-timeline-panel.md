# P3.3 Timeline panel

**Work package:** P3.3, needs P2.1 and P3.1 (done). **Status:** implemented on branch `wp/p3.3-timeline`.

## Decisions

- **Rows.** One row per object on the slide's base layer; the top row is the front object. Each row: hide/show in editor, lock, name (double-click to rename), bring forward / send backward, and a bar for when the object is on stage. Clicking a row selects the object.
- **Bars.** Drag the body to move the start, the left edge to change the start keeping the end, the right edge to change the length. Times land on tenths of a second. A right edge dragged to the end of the timeline or past it becomes "until end". Each drag is one undo step.
- **Playhead and the stage.** Normally the stage shows every object, whatever its timing, so anything can be edited. While the playhead is being dragged, or Play is running, the stage shows only what the engine shows at that time: `visibleAt` (`timeline-preview.ts`) asks a real engine (`jumpToSlide`, `seek`, `getView`), so it cannot drift from preview and published courses. Releasing or reaching the end returns to showing everything; the playhead stays where it was for "Align to playhead".
- **Toolbar** (one line; scrolls sideways in a narrow panel): Play/Pause, time, Length, zoom out/in (20 to 320 px per second), Until end and To playhead (selected objects), add and delete cue point. The ruler stays pinned while rows scroll.
- **Cue points** are added at the playhead, dragged along the ruler, and deleted when selected.
- **New commands** (no format change): `layer.setDuration` (cue points beyond the new end move back to it), `cuePoint.add`, `cuePoint.update`, `cuePoint.remove` (also removes triggers listening for it).
- Not here: overlay layers' timelines (P4.2), audio rows (P6.1), drag-to-reorder rows (buttons instead), renaming cue points in the UI (the command supports it), Master View timelines (shown, but the stage is not filtered there).

## Tests

- Model: cue and duration commands, undo, rejections, trigger clean-up, and steps in the undo/redo property test.
- `e2e/timeline.spec.ts` (4): the stage while scrubbing equals the engine's own output at each time; rows, bars and bar drags; row toggles, rename, reorder, until end, align; cue points, length, zoom, play.
