# P4.2 Variables

**Work package:** P4.2, needs P3.1 (done). **Status:** implemented on branch `wp/p4.2-variables`. No saved-format change: `project.variables` was already in the schema.

## Decisions

- **Commands** `variable.add`, `variable.update` (name, type, default; type and default must agree), `variable.remove` (also removes triggers that read or set it). Names are unique ignoring case and may not be a built-in name.
- **Rename updates references.** Text refers to variables by name (`%Name%`), so a rename rewrites every reference in every rich text: objects' text, states' text overrides and slide notes, matching the old name ignoring case. One undo step.
- **Delete with a usage check.** `variableUsage` counts text references and triggers. The manager deletes an unused variable at once and asks first ("Used N times") otherwise. After deletion, `%Name%` stays in the text as written.
- **Built-in variables** come from the engine and are read-only: `SlideNumber`, `SlideCount`, `SlidesViewed`, `PercentComplete` (slides visited, rounded) and `ElapsedSeconds` (whole seconds of the session, saved in `SessionState.e` and restored). Quiz results join them in P7. `ElapsedSeconds` sends a `variableChange` each whole second; the others change only on slide entry, when the slide is drawn afresh anyway.
- **Showing values.** `RenderContext.variables` (optional) turns `%Name%` into the current value. The player passes the engine's values and redraws objects whose text could contain a reference when any variable changes. The editor passes nothing, so authors see the reference. Numbers show locale-neutrally (`12.5`). A name nobody knows stays as written; values are text, never markup.
- **UI.** Variables manager dialog (Insert tab → Variables, and a button in the Triggers panel): name, type, default, usage count, delete; built-ins listed for reference. Text Format tab → Insert variable: lists the project's and the built-in variables; inserts at the caret while editing, or starts editing and adds it at the end.

## Tests

Model (rename rewriting, refusals, type and default, removal with triggers, usage), engine (built-ins, elapsed time across a restore), render (substitution and escaping), player (live update in a browser), e2e `e2e/variables.spec.ts` (3) and the theme audit.
