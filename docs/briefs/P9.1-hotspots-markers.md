# P9.1 Hotspots and markers

**Work package:** P9.1, the first of Phase 9. It needs Phase 8, which is done and was reviewed in session 63.

**Plan line:** hotspots and markers (markers with title, text, media, audio; pulse animation).

**What they are:**

- A **hotspot** is an invisible area of the slide to click. It is a target for triggers, with no look of its own. Use it to make part of a picture clickable.
- A **marker** is a small round icon that opens a label when the learner clicks it (or points at it). The label has a title, some text, and optionally a picture or video, and it can play a sound as it opens. A marker can pulse to draw the eye.

**My design choices**, listed for Luke to change (the same practice as Phase 8):

1. **Hotspots:**
   - **Shape:** a rectangle or an ellipse. The ellipse is clickable only inside the ellipse.
   - **In the editor** a hotspot shows as a dashed outline labelled "Hotspot", so it can be found and selected, as zoom regions are. In a course it is invisible.
   - **Hotspots are keyboard-reachable.** They exist only to be clicked, so in a course each is a button in the tab order, named by its alt text (or its name), and Enter or Space clicks it.

     The Phase 7 review noted that other clickable objects are not keyboard-reachable yet; that is still open. Hotspots do not wait for it, because they would be useless to a keyboard user otherwise.

   - Triggers, states, timing and layers work as for any object.
2. **Markers:**
   - **Icon:** plus, info, question, pin or star, drawn in our own simple shapes, in a colour of the theme (or any colour). The marker's frame is the icon; a new one is 36 × 36.
   - **The label:**
     - a title, and plain text (a line a paragraph);
     - optionally a picture or a video (a course asset);
     - optionally a sound, which plays when the label opens and stops when it closes.
   - **Opening:**
     - **On click** (the default): a click opens it, another click closes it. Escape and clicking elsewhere close it too.
     - **On hover:** pointing at the marker opens it, and moving away closes it. Keyboard focus opens it too.

     Only one label is open at a time.

   - **Placement:** the label opens beside the marker: to its right, or to its left when there is no room. It is kept inside the stage. It is up to 320 stage pixels wide.
   - **Pulse:** an expanding ring around the icon, off by default. The learner's reduced-motion setting turns it off (session 45's rule).
   - **Triggers:** a marker is also an object. Clicking it runs its click triggers as well as opening the label.
   - **For the keyboard:** a marker is a button with `aria-expanded`, named by its title. The label is a region named by the title.
   - **Where it lives:** the label is the player's, drawn over the stage. It is not saved in the session, and a slide change closes it. Its sound plays at the learner's volume and speed (P8.1), outside the timeline.

## Saved format version 26

```ts
HotspotObject { …objectBase, type: 'hotspot', props: { shape: 'rect' | 'ellipse' } }
MarkerObject  { …objectBase, type: 'marker', props: {
  icon: 'plus' | 'info' | 'question' | 'pin' | 'star',
  color: Color,
  title: string,              // up to 200
  body: string,               // up to 5000, a line a paragraph (not `text`, which is rich text elsewhere)
  media: AssetHash | null,    // a picture or a video
  audio: AssetHash | null,    // a sound
  opensOn: 'click' | 'hover',
  pulse: boolean,
} }
```

- **Validation:** `media` is an image or video asset, and `audio` is an audio asset.
- **Migration 25 → 26:** nothing to change.
- **Legacy fixture:** `v25-two-slides`.

## Runtime

- **Render** (`packages/render`):
  - `hotspot`: nothing in a course or thumbnail; a dashed outline and "Hotspot" label with `mediaMarkers` (the editor's stage).
  - `marker`: the icon, everywhere, with `data-pulse` when it pulses.
- **Player:**
  - hotspots and markers get button semantics;
  - the marker label (`packages/player/src/markers.ts`): opening, closing, placement, the sound, keyboard;
  - a slide change, a lightbox, or leaving the course closes it.

## Editor

- **Insert → Hotspot** (draw a rectangle; its shape can be changed after) and **Insert → Marker**.
- **The Format panel:**
  - a hotspot's shape;
  - a marker's icon, colour, title, text, picture or video, sound, opens on click or hover, and pulse.
