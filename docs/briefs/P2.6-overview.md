# P2.6 Overview

**Work package:** P2.6, needs P2.1 (done). **Status:** implemented on branch `wp/p2.6-overview`.

Plan line: scenes as containers of slide thumbnails; add, rename, reorder, duplicate, delete scenes and slides; drag slides between scenes; set starting scene; thumbnails generated off-screen and cached. Link arrows wait for triggers (P4).

## Decisions

- **No schema change.** The starting scene is the first scene (`project.scenes[0]`, see the schema comment), so "Set as starting scene" is `scene.move` to index 0. The Overview marks the first scene "Start".
- **Duplicating** builds copies in `@vedraopus/model` (`cloneSlide`, `cloneScene`): every id is new and a copy's triggers point at the copy's own objects and layers. The copy is added with the existing `slide.add` / `scene.add`, so it is one undo step. A duplicated slide goes after the original; a duplicated scene after its source.
- **Thumbnails** draw the real slide with `@vedraopus/render` (same path as the stage), scaled to the card. A card is a memoised component keyed by the slide object, which is unchanged unless the slide changed, so unchanged slides are never re-rendered ("cached"). Objects are drawn static and not interactive. The slide list in the left panel uses the same component.
- **Rename** is inline (an input in place of the name; Enter commits, Escape cancels). `window.prompt` does not work in Electron.
- **Drag and drop** (HTML5) moves a slide before another slide or to the end of any scene, including an empty scene, with `slide.move`. Scenes reorder with Move earlier / later buttons (`scene.move`).
- **Delete**: slide delete is allowed down to zero slides (existing behaviour); the last scene cannot be deleted (command rule).
- Commands run through `history.execute` outside a gesture, so autosave sees each one.

## Done when

- Unit tests: clone gives fresh ids and remaps triggers; duplicated scene validates.
- e2e: add, rename, duplicate, delete slides and scenes; drag a slide to another scene; set starting scene; thumbnails show slide content; each undoable.
