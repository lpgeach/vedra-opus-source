## P9.2: what was done

The brief is `docs/briefs/P9.2-data-entry.md`; the design choices I made are listed at its top, for Luke to change.

- **Model, format 27:**
  - text entries get `variable` (a text variable, or a number one for a numeric field), and `min`/`max` (numeric only);
  - the event `controlLosesFocus` (a text entry or dropdown);
  - validation of the binding's type, the limits, and the event's object;
  - `variable.update` (type) and `variable.remove` unbind fields that no longer match;
  - migration 26 → 27, with a new helper `eachSavedObjectV27` that also walks question banks;
  - legacy fixture `v26-two-slides`.
- **Engine:**
  - a bound field's view shows its variable, unless the learner is typing in it;
  - `engine.blur(id)` writes the variable (text as typed; numbers read locale-neutrally, blank as 0, clamped to the limits, words refused), then raises `controlLosesFocus`;
  - a question's own fields keep what was typed for the question;
  - fields are taken on any layer, no longer the base layer only.
- **Player:** `focusout` on a field calls `engine.blur`; Enter in a one-line field blurs it.
- **Editor:**
  - Insert → **Data Entry** (Text Entry, Numeric Entry) and a `field` icon;
  - the Format panel's field section: placeholder, variable (of the field's type only), and least and greatest for numeric fields;
  - the trigger wizard's event "a control loses focus", described as "when … loses focus".

# P9.3 checkboxes and radio buttons (same session)

**Branch**: `wp/p9.3-checkboxes-radios`, from `master` after P9.2 (PR #71).

The brief is `docs/briefs/P9.3-checkboxes-radios.md`; the design choices are at its top, for Luke.

## What was done

- **No new object type and no format change.**
  - `createCheckboxObject` (a square choice, no group) and `createRadioObject` (a round choice whose button set is its group) build on P7.1's choice object.
  - Plan §5's rules already toggle Selected and keep one per button set.
- **Player:** every choice on a slide, not only a question's, is a checkbox or radio:
  - `aria-checked`, its words as its name, in the tab order, Space and Enter;
  - the arrow keys move along a radio group and select, without changing slides.
- **Editor:**
  - Insert → Data Entry → Checkbox and Radio Button. A new radio joins the selected radio's group, else names `Group n`.
  - The Format panel's Checkbox / Radio button section: the group's name, and Starts checked. It is not shown for a question's own choices.
