## What was done

- **Model, format 20:**
  - `project.player`:
    - the course title and a logo (an image asset);
    - the menu: shown or not; free, restricted or locked navigation; the author's entries (titles and hidden slides);
    - the controls: seekbar off, view or drag; Submit; volume; captions; speed; full screen; accessibility.
  - Migration 19 → 20 gives the defaults; legacy fixture `v19-two-slides`; current fixtures migrated.
  - Validation: entries name scene slides only; the logo is an image.
  - Removing a slide drops its entry.
  - `project.setPlayer` is in the undo/redo property test.
- **Engine:** `submitQuestion()`, for the player's own Submit button.
- **Player:**
  - `packages/player/src/frame.ts` builds:
    - the menu tree (scenes in order, author titles, hidden entries left out, a draw slide as one entry for what it drew, bank slides never);
    - what each navigation allows;
    - the seekbar;
    - Submit, on question slides only;
    - volume and the speed choice;
    - the accessibility panel (caption size, keyboard shortcuts);
    - full screen;
    - the logo.
  - Speed is a clock of the player's own (`speedClock`), given to the engine, plus each media element's `playbackRate`.
  - Volume is a level times each media's own (`Soundboard.setLevel`).
- **Editor:** Design → **Player…**: features, the logo picker, the controls, the seekbar mode, and the menu with a title field and Hide checkbox per slide. Each change is one undo step.

## Found and fixed

- **WebKit keeps a media element's volume as a 32-bit float** (0.5 reads back as 0.5000012). The soundboard compared volumes exactly, so in WebKit it set the volume on every frame. It now compares within 0.001; the browser test does too.
- **Speed set every frame** would undo a video's own speed control. `playbackRate` is now set only when the learner's speed changes.
- The first browser test clicked Menu again while the menu was open, which closes it. The test was wrong, not the player.
