Release work Luke asked for after the plan was built: the notices page in the app and the source offer (`docs/briefs/R2-notices-and-sources.md`). R1 (session 105) made our own ffmpeg on every system first, so the source offered is a handful of archives.

## Found while planning it

**The npm libraries' notices did not reach anyone.** `docs/licences.md` said their licences "travel in `node_modules`". But the app bundles every package into its own files (`externalizeDeps: false`) and ships no `node_modules`, so their copyright and permission notices were nowhere in the package. The same holds for the course player, which is in every published course. MIT, BSD, ISC and the like ask for those notices to go with copies.

## What was done

- **`scripts/third-party-notices.mjs`,** a Vite plugin in the app's three bundles and the player's. After each build it reads the bundle's module graph and writes `third-party-notices.json` beside it: each npm package built in, with its version, licence, and the text of its licence and notice files. Our own packages are left out.
  - As built today: main 22 packages, preload none, renderer 52 (React, TipTap and ProseMirror, Zod, the Inter font under OFL, and others), the player 2 (Immer, Zod).
  - TipTap's 28 packages and `lazy-val` name MIT but carry no licence file. They get MIT's standard text with the copyright from their `package.json`, marked as such. The standard text is kept only for MIT; nothing else is written by hand.
- **Help → Third-Party Notices…,** with or without a project open (`main/third-party.ts`, `ThirdPartyNoticesDialog.tsx`; its words in the string catalogue):
  - the source offer first;
  - what ships beside our code:
    - Electron with Chromium: Electron's licence shown, Chromium's notices opened outside the app;
    - FFmpeg: its `SOURCE.txt` and the LGPL;
    - LibreOffice: its `NOTICE`, with `LICENSE.html` opened;
    - Lucide, Open Doodles, and the SCORM schema files' credit;
  - every library built in, with where (editor, player or both) and its text on request.
  - The renderer names a file to open by its id; main opens only the files it listed.
- **Every published course's `THIRD-PARTY-NOTICES.txt`** now carries the player's libraries' notices (`playerLibraries`), before any drawing sets'. Every course therefore has one file more.
- **`npm run collect:sources`** (`scripts/collect-sources.mjs`) gathers a release's source into `release-sources/`, which git ignores:
  - ffmpeg's seven archives, read from `build-ffmpeg.sh` itself, and the script;
  - LibreOffice's `libreoffice-26.8.3.1.tar.xz`, with The Document Foundation's SHA-256;
  - a README.
- **`docs/releasing.md`:** attach the files to each release, and keep them three years.
- **`docs/licences.md`:** where the notices are; the "not done yet" rows done.
- **The page as shown:** screenshots in both themes (taken headless in WSL by a throwaway spec, not committed) found the dialog held to the general 520 px and the buttons wrapping; fixed (760 px, the buttons kept together), and seen again.
