## Technical Details

### Monorepo Structure
```
project-eloquent/
├── package.json          # Root with workspaces
├── frontend/             # React SPA (workspace)
├── backend/              # Express API (workspace)
└── shared/               # Shared types (workspace)
```

### Available Commands
- `npm install` - Install all dependencies
- `npm run dev` - Run frontend + backend
- `npm run dev:https` - Run with HTTPS
- `npm run dev:frontend` - Run frontend only
- `npm run dev:backend` - Run backend only
- `npm run generate:certs` - Generate SSL certificates

### HTTPS Configuration
- **Frontend**: Vite with `--https` flag
- **Backend**: Express with self-signed certificates
- **Certificates**: Generated in `backend/certs/`
- **Files Needed**: `localhost-key.pem` and `localhost.pem`
