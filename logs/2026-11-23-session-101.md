## What was done

- **`electron-updater`** 6.8.11 (pinned; pure JavaScript), behind our own `Updates` wrapper.
- **Help menu:**
  - Check for Updates… checks once and says what it found;
  - Check for Updates Automatically (off until ticked) checks at start and daily, and speaks only of an update;
  - Update Channel: Stable or Beta (prereleases).
- **Choices at each step:**
  - a newer version is offered (Download or Later);
  - once downloaded, Restart Now or install When I Quit;
  - nothing downloads or installs unasked, and nothing goes back to an older version.
- **Development builds check nothing**, and say so. A test can give a feed through `VEDRAOPUS_UPDATE_FEED`.
- **A deb install** is offered the releases page; Windows, macOS and the AppImage update in place.
- **The feed:** this repository's GitHub releases (`publish` in `electron-builder.yml`).
- **`docs/releasing.md`:** how to publish a release that installed copies will find.
