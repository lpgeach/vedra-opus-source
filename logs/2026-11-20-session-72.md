## What was done

- **The library data:**
  - `scripts/build-library.mjs` downloads `lucide-static` 1.77.0 and `react-open-doodles` 1.0.5 from npm, and checks each against the registry's SHA-512;
  - it writes plain drawings to `apps/desktop/src/renderer/library/` (2,098 icons and 33 illustrations), and the two licences to `apps/desktop/resources/licences/`;
  - the doodles' code is parsed with the TypeScript parser and never run;
  - the output is committed. No npm dependency was added.
- **Model, format 32:**
  - `graphic` objects hold their own drawing: a tree of plain shapes, whose attributes come from a fixed list and are each checked by a pattern;
  - paints are `ink`, `accent`, `none` or a hex colour; the object's `ink` and `accent` colours can be theme colours; icons have a line width;
  - at most 5,000 shapes;
  - `createGraphicObject`;
  - migration 31 → 32 changes nothing; legacy fixture `v31-two-slides`.
- **Render:** an inline SVG kept in proportion. It is `role="img"` named by its alt text, or hidden from screen readers when decorative.
- **Editor:**
  - Insert → **Icons…**: a dialog with Icons and Illustrations tabs, a search by name and tag (the exact name first), up to 240 results drawn, and the credits;
  - the library loads only when the dialog first opens, as two separate chunks;
  - the Format panel's Icon or Illustration section: ink, accent (illustrations), line width (icons).
- **Licences:**
  - installers carry `resources/licences/` (electron-builder's top-level `extraResources`);
  - `docs/licences.md` records both sets, and asks Luke whether published courses should carry Lucide's notice.

## Mistakes this session

- **A script that imported a downloaded package's code** was refused by the tool's safety check. It now parses the code instead (pitfall #126).
- **`npm install --legacy-peer-deps`** dropped the Windows installer's optional packages from the lockfile. It was undone at once, and no dependency was added.
- **Prettier reformatted the generated data** to 90,000 lines; it was written back compact, and the files are in `.prettierignore`.
- **A first WSL run used a stale checkout:** the visual reference made there blocked the pull. The run was repeated on the right commit.
