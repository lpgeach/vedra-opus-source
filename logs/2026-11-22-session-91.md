P11.2 starts here. There was no brief, so one was written first (`docs/briefs/P11.2-templates.md`). It splits the package into three parts:

- A: save as template and new from template;
- B: import slides;
- C: built-in starter templates.

A template is an ordinary project file in a templates folder: no new format and no saved-format change.

## What was done

- **File → Save as Template…** asks for a name (the project's title suggested) and writes a copy of the project, with its media, to `<userData>/Templates/<name>.vedraopus`.
  - A name already there is replaced after asking.
  - The open project, its file and its unsaved state are not changed.
- **File → New from Template…**, and a button of the same name on the Welcome screen, open the template chooser:
  - built-in templates (none until part C), then the author's own, each with its slide count and stage size;
  - a template that cannot be read says why, and cannot be used;
  - the author's own can be deleted, after asking; **Browse…** takes any project file.
  - Using one opens a new, unsaved project with a new id and no file of its own.
- **Main:**
  - `readContainerProject` reads a file's project without unpacking its media;
  - `templates.ts` lists, names and checks templates;
  - `ProjectSessions` saves, opens and removes them;
  - IPC: `template:list`, `template:saveCurrent`, `template:open` and `template:remove`.
- The words are in the string catalogue.

## Tests

- **Unit** (`templates.test.ts`):
  - the list: built-in then own, by name, with slides and size; a damaged file listed with its reason; a missing folder an empty list;
  - reading a file's project without its media;
  - safe file names;
  - deleting only the author's own templates, not built-in ones, not files elsewhere, not through `..`.
- **e2e** (`templates.spec.ts`):
  - a project with a picture saved as a template, the open project still unsaved and unchanged;
  - a new project from it through the chooser, unsaved, its picture loaded;
  - the template deleted;
  - from the Welcome screen, Browse… starting a project from the two-slides fixture.
