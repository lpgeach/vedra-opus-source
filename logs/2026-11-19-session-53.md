# Session 53 — 2026-11-19

## What this session was for

P7.5, feedback:

- correct, incorrect and try-again layers generated from feedback masters;
- Submit behaviour, and the `submit interaction` action;
- review mode, showing the learner's answers and the correct ones.

Worked on the Windows machine straight after session 52 (P7.4, merged in PR #57), with the Linux checks in WSL.

**Luke's decisions (asked at the start; the recommended option each time):**

1. An editable feedback master in Master View, copied as layers onto each question slide.
2. The feedback words live in the layers' text objects; the old strings move there in the migration.
3. Review mode as an engine and player mode, turned on by a `reviewQuiz` action. Result slides come in P7.7.
4. Feedback by choice shows the picked choice's own words on the shared Correct or Incorrect layer.

There is no AI attribution in any commit or in the PR.

## Done

On `wp/p7.5-feedback`: the brief, then steps A, B and C, and one fix commit.

### Step A: format 17

- **Masters:**
  - each master has a `kind`, and each layout a `role`;
  - every project has exactly one feedback master, with Correct, Incorrect, Try Again and Thank You layouts;
  - slides cannot use feedback layouts;
  - the master commands refuse to delete the feedback master or add layouts to it.
- **Question feedback:** the strings are replaced by `FeedbackPart`s (`layer`, `message`, `button`), and validation checks them.
- **Model functions:**
  - `createFeedbackMaster`, `createFeedbackLayer`, `addFeedbackLayers` and `feedbackRolesFor`;
  - `feedbackParts`, `mapFeedbackParts` and `withoutLayer`;
  - `layer.remove` and `object.remove` now update the question.
- **Generating layers:** new question slides and converted slides come with the layers they need. Try Again comes only when the question has a try to spare.
- **Migration 16 → 17:**
  - marks masters and layouts;
  - adds the default feedback master, copied from frozen data (`migration-v17-data.ts`) and scaled to the stage;
  - moves each question's old words onto layers made from it.
- **Legacy fixtures:** `v16-two-slides` and `v16-quiz`. The current fixtures were brought to format 17 by running them through the migration.
- **Editor:**
  - Master View lists the feedback master last, with Add layout and Delete disabled for it;
  - the layout picker offers slide masters only;
  - Form View's Feedback row has a box per layer, editing its message, or a "Make the … layer" button when the layer is missing;
  - the trigger wizard knows the two new actions.

### Step B: Submit

- Submit shows the result's layer and waits. `continueQuestion`, on the layer's button, closes it and takes the branch, or leaves another try.
- With feedback none, or the layer gone, Submit branches at once, as before.
- **By choice:** the message shows the picked choices' feedback, each on its own line (`ObjectView.text`). The player redraws the message with those words.

### Step C: review

- `reviewQuiz` turns review on and goes to the first question.
- **While reviewing:**
  - `questionClosed` locks every input;
  - Submit and the feedback layers stay quiet;
  - Next is never held;
  - a P7.2 hotspot's spots show.
- **Marks:** `ObjectView.review` is `right` or `chosen`, for the choice, entry, dropdown, drag and hotspot kinds.
- **The player:**
  - the slide's result is shown in a banner (`EngineView.review`);
  - the right answer gets a green outline and a wrong choice a red one.
- Review is not saved.

## Tests changed, and why

Generated question slides now carry hidden feedback layers, and Submit waits for Continue. So:

- **Marking tests:** engine tests (graded, survey, freeform, quiz), the suspend codec tests and the player browser specs build questions with feedback `none` (a `quizSlide` helper), keeping the immediate-branch path tested. The new feedback tests cover the layers.
- **Published courses in e2e:** Submit now goes through `submitAnswer` in `e2e/course.ts`, which presses the layer's Continue when one appears. Shape counts look only at visible shapes.
- **Survey label:** the "Thank-you feedback" label is now "Thank You feedback".
- **Older migration tests:** the animations and transitions migration tests count only the project's own masters, not the feedback master format 17 adds.
- **Master command tests:** they find their master by id.
- **Format 15 and 16 tests:**
  - the format-15 multiline test now builds a true old-shape project (no feedback master, words on the question);
  - the format-16 test checks the slides are unchanged rather than the whole document.
- **Property test:** it no longer removes the feedback master or lays slides out on it, and conversions now add their layers.

After each change the full suite was rerun.

**A real bug the property test found:** the default feedback master's sizes went negative on a tiny stage. They are now clamped.
