## Found and fixed

**The Phase 11 e2e's update check assumed the development app.**

- In development, Check for Updates… says updates are checked only in installed copies. A package does check.
- The unpacked Windows and macOS builds have no `app-update.yml`, so the updater failed on reading its settings, before any request: nothing left the machine. A real installer has that file, and a check the author asks for then reaches GitHub, as designed.
- The test now gives the app an update feed on this machine that nothing answers (`VEDRAOPUS_UPDATE_FEED=http://127.0.0.1:9/`). The check then behaves the same in both, is made only when asked, and never reaches the network.
- It passed against the development app and the Windows and macOS packages.
