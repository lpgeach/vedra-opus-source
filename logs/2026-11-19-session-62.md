## What was done

- **Already there, and checked rather than rebuilt:**
  - the resume prompt (P5.1, with P8.3's look and words);
  - the result actions (P7.7).
- **Model, format 25:** the actions
  - `restartCourse`, `exitCourse`;
  - `sendEmail { to, subject, body }`, `printSlide`;
  - `openFile { asset }`, `setFocus { object }`, `seekTimeline { layer, time }`.

  Also:
  - validation: the email address has no `?`, `&` or `#`; the file is a file or picture of the course; the object and layer are the slide's own;
  - the label `courseEnded`;
  - migration 24 → 25 (nothing to change); legacy fixture `v24-two-slides`.
- **Engine:**
  - `restart()` resets variables, slides seen and their memory, answers, results, timers and review, draws again, and goes to the first slide. It keeps completion and elapsed time, and closes a lightbox.
  - New events: `exitCourse`, `print`, `openFile`, `focus`.
  - `sendEmail` raises `openUrl` with a `mailto:` link, filled in and encoded.
  - `seekTimeline` shares the seekbar's `seekLayer`.
- **Player:**
  - exit calls `options.onExit`, tries `window.close()`, then shows "The course has ended…" over an inert frame;
  - print calls `window.print()`, with a print stylesheet that hides the frame;
  - open file opens the file in a new tab;
  - focus moves keyboard focus to the object, skipping a hidden one.
- **LMS:** `startCourse` gives `onExit`. It finishes the session (commit and terminate) and, with cmi5, goes to the return address.
- **Editor:** the trigger wizard offers all seven, with fields for the email, the file, the object, and the layer and time.
