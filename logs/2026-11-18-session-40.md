## Luke's decisions

All four came before the code, because the first touches plan §5:

- **Exit timing:** the exit *finishes* at the object's end, playing during the last part of its bar. §5 is reworded to say so.
- **Path clock:** a running path pauses with its timeline (or a hidden layer) and carries on after the timeline ends.
- **By paragraph:** the duration is per paragraph, so 4 × 0.5 s takes 2 s.
- **Adding a path** also adds "move along path when the timeline starts".

## Done

- **Brief:** `docs/briefs/P6.5-animations.md`, written first.
- **Model (saved format 9):**
  - every object has `animations { entrance, exit, motionPaths }`;
  - twelve effects (fade, fly, float, wipe, split, iris, grow, zoom, spin, spin and grow, bounce, swivel), each with its own directions;
  - paths are a line, an arc (start, through, end) or freeform, with duration, easing and relative start;

- **Validation:**
  - directions per kind;
  - by paragraph only with text;
  - no animations inside groups;

- **Commands:**
  - `object.update` takes `animations`; removing a path or an exit takes its triggers;
  - grouping drops the members' animations and their triggers.
- **Triggers:** new action `moveAlongPath` and new event `animationCompletes`.
- **Fixed on the way (a P6.4 bug):** duplicating a slide or pasting a sound kept caption ids, which made the project invalid.
  - `renewObjectIds` now renews object, caption and path ids for clone and paste.
  - `idsInObject` lists captions and paths, so `object.add` refuses duplicates.
- **Engine:**
  - `ObjectView.effect` (phase and seconds in) is worked out from the playhead.
  - **Path runs:**
    - they run on the engine clock and pause with the layer;
    - seeking forward advances them; seeking back leaves them where they are;
    - a run gets credit for the playhead time since the event that started it, and a finished path reports how late it finished (`lateBy`).
  - `ObjectView.offset`; offsets are saved for slides that resume (`SavedSlide.m`) and reset on reshown overlays.
  - `animationComplete` events for entrances, exits (just before the object leaves) and paths.
  - An exited `untilEnd` object takes no input.
- **Render:** `animation.ts` provides:
  - `effectKeyframes` (opacity, transform with the object's own turn kept, clip-path in pixels);
  - `objectBounds`;
  - `createAnimator`, which keeps paused Web Animations and sets their `currentTime` from the engine; it animates by paragraph too, and applies motion through the `translate` property.
- **Player:** runs the animator on every frame.
- **Editor:**
  - **Animations ribbon tab:** entrance and exit effect, direction, duration and by paragraph; Add line or arc path, Draw freeform, choose a path, its duration, easing, relative start, and Delete.
  - **On the stage:** paths with handles, a ghost of where the object ends, drag a handle (one undo step), and draw freeform (simplified to at most 50 points; Escape cancels).
  - **Timeline:** shading for the entrance and exit.
  - **Scrubbing:** the stage animates through `previewAt`.
  - **Trigger wizard:** the new action and event, with their sentences.
  - `Group` and `Command` moved to `ribbon-parts.tsx`, so the tab can live in its own file.

## Mistakes this session, and what changed

- **Crediting every run on a layer.** `startRun` credited the time since its event to every run on the layer, not only the new one. The seek test caught it (200 instead of 150).
- **A chained path lost its overshoot.** The engine test caught it; paths now report `lateBy`.
- **A test that proved nothing.** My first player test used "complete course" as the path's trigger, but a one-slide course is complete on entry. It now sets a variable. Lesson: check that the thing asserted could have been false.
- **Comparing a style string.** Chromium writes `100px 0px` back as `100px`. The test measures the box instead, and the animator no longer compares strings.
- **Substring names again** (`getByLabel('Motion path')`). This is now rule 15 in "Mistakes I keep making".
- **Lint ran after typecheck** and found an unused starting value in the new e2e spec. That's fine, but it is a reminder to run all of format, typecheck and lint before a long e2e run.
