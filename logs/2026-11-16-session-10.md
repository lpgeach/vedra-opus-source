## Done

- Implemented TipTap-based in-place rich text editing on stage for text boxes and for text inside shapes/buttons:
  - Double-click enters edit mode; editor overlay renders in place with the object frame/padding/alignment.
  - Edits commit via `object.update` (text `props.text`, and for `growShape` text objects the frame height when needed) so changes are undoable through existing history commands/gestures.
  - Escape commits (Shift+Escape cancels) and focus loss/unmount commits the latest content.
- Added formatting/autofit controls in the ribbon (font family/size, bold, italic, underline, colour, alignment, bulleted/numbered lists, link, line height, paragraph spacing before/after, and autofit mode for text objects).
- Replaced provisional rich-text rendering in `@vedraopus/render` with a static serializer supporting paragraphs, marks (bold/italic/underline/strike/code/textStyle), links, alignment, line/paragraph spacing, lists, and text blocks for text boxes/shapes/buttons.
- Added text autofit support: `render` emits autofit hints and `applyTextAutofit`/`measureGrowHeight` helpers; stage/editor apply shrink-to-fit in DOM and commit grow-shape frame updates on edit commit.
- Bundled Inter font assets for deterministic rendering and added shared rich-text/editor styling.
- Added `packages/render/visual/text-parity.spec.ts`: compares editor rendering and static rendering of the same rich-text document by screenshot (pixel-equal buffer comparison) in the render visual test harness.
- Updated `docs/briefs/P2.4-text.md` status and ticked P2.4 in `docs/PLAN.md`.
