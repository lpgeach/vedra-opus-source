## What was done

- **Export Word document…** in the Translation dialog writes a `.docx`:
  - the course title;
  - one line of instructions for the translator;
  - a table: the id (small and grey, with the note under it), the source, and an empty column for the translation.

  The header row names the two languages. The page is landscape A4, for room. It is written in main (`apps/desktop/src/main/translation-document.ts`) with `yazl`, which the app already uses. There is no new dependency.
- **Import translation…** now takes either kind of file. A document is read in main with `yauzl` and the model's XML reader:
  - each row's id (the first line of its first cell), its source and its translation;
  - a cell's paragraphs as lines;
  - every `w:t`, however Word split the runs;
  - tracked insertions read, tracked deletions not.
- **Formatting** is `[1]…[/1]` and `[br]` in the document (`taggedText` and `fromTaggedText` in the model). A new line typed in a cell counts as a break.
- Electron's "Error invoking remote method" is taken off the front of messages from main, so the dialog says just why a file was refused.

## Tests

- **Main** (`translation-document.test.ts`):
  - a document written and read back;
  - a document in the shape Word saves (split runs, proofing marks, revision ids, a bookmark, a tracked insertion and deletion, more namespaces), read as Word means it;
  - refusals for a file that is not a document, a document with no table, and a table that is not ours.
- **Model** (`translation-text.test.ts`): tags written and read, new lines as breaks, and stray tags kept for the import to refuse.
- **e2e** (`translation.spec.ts`, a second test): a course exported as a Word document, its third column filled (as a translator would, by editing the document's XML) and imported. Every piece is translated, and the slide shows the German.

**Not done as the brief first said:** it asked for "a fixture made by Word". There is no copy of Word here, so the Word-shaped document is made by hand in the test, from what Word writes, and the test says so. The brief now says this.
