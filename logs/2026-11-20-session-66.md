## Mistakes this session

- The first version of the mass-rename script used TypeScript's non-null assertion in JavaScript and failed to parse; it was fixed before any file was changed.
- The WSL clone was still at the pre-merge P9.1 commit, so the first patch application failed on changed context. Fetching `origin/master` and applying the patch there fixed it.
- A PowerShell-to-WSL command with nested quotes broke a log-summary grep; a simpler quoting form gave the counts above.
- The first Windows Firefox rerun failed at a different assertion from the full run, which is why it was compared against a clean baseline rather than treated as a rename regression.
- After Save As was tightened to replace a legacy extension, the new e2e test still tried to create the legacy file with Save. Save now writes `.vedraopus`, so the file was never made and the full e2e run failed at the reopen step. The test now saves with the current extension and renames the file to `.eloquent` before relaunch.
