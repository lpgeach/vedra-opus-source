## Not done or not verified

- **No xmllint test in the repo.** xmllint is a system tool, not a dependency, and a test that skips without it would be a weak check. The validation was a one-off; pitfall #79 says how to repeat it.
- **`imsmd_rootv1p2p1.xsd` will not compile in libxml2** (non-deterministic content models in the 2001 IMS file). The manifest uses no metadata elements, so it is not checked against it. LMSs commonly ship this same file.

## Mistakes this session, and what changed

- My first xmllint run used `--schema imscp_rootv1p1p2.xsd` alone and reported a false failure on `adlcp:scormtype`, because the ADL schema was not loaded. Validation needs a wrapper that imports both; recorded in pitfall #79.
- I saw `ims_xml.xsd` printed on one line and took it for bare CR line endings. I changed the generator before checking the bytes (`od -c`), which showed the file has no line breaks at all. The change does no harm, but I should look at the bytes first.
