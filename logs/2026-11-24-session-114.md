## What was done

- **Studied the format** from the two samples, with throwaway scripts kept in the scratchpad. It is written up in `docs/briefs/B5-storyline-import.md`; the traps are in pitfall #167. The hardest part was finding which stored file is which media item. Nothing in the format says; `media.ts` works it out from constraints.
- **`apps/desktop/src/main/import/storyline/`:**

| File             | Does                                                                                                                                                                                                                                               |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `package.ts`     | Reads the zip: XML into memory within limits; media left in the zip, extracted in one pass when wanted.                                                                                                                                             |
| `media.ts`       | Which file each media item is.                                                                                                                                                                                                                       |
| `colour.ts`      | The master's scheme into our theme; colours with shade, tint and alpha.                                                                                                                                                                              |
| `text.ts`        | The rich-text document into ours: paragraphs, lists, bold/italic/underline, size, colour and font.                                                                                                                                                   |
| `convert.ts`     | Scenes and slides, the stage, backgrounds, master and layout objects, pictures, text, shapes, sound, video, groups, hotspots, timing, entrance and exit, states, layers, variables, triggers with conditions, and notes. The report says what is left out. |
| `import-file.ts` | Media into the workspace (sound and video through the pipeline), convert, then `parseProject`.                                                                                                                                                      |
| `test-story.ts`  | A small course made by our own code, for tests.                                                                                                                                                                                                       |

- **In the app:**
  - **File → Import Articulate Storyline Course…** and the Welcome screen's **Import Storyline Course…** open a new, unsaved project, with the import report.
  - The report now words itself by its source: "Storyline import", "The course".
