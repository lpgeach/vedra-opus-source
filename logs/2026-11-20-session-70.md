## What was done

- **Model, format 30:**
  - `web` objects: a source (an http or https address, or a folder's files by path with a start page), in the slide or in a new window, and a title;
  - `WEB_URL` and `WEB_PATH`;
  - validation of addresses, paths, the start page and the files' assets;
  - `createWebObject`;
  - migration 29 → 30 changes nothing; legacy fixture `v29-two-slides`.
- **Render:**
  - in a course, a sandboxed frame (`allow-scripts allow-forms allow-popups`, never `allow-same-origin`, no referrer) or a button;
  - elsewhere, a placeholder;
  - in Preview, an address's placeholder has "Open in browser".
- **Publish:**
  - folders go to `content/web/<id>/<path>`, listed in SCORM manifests, and not again under `content/assets/` unless something else uses a file;
  - `index.html` tells the player where folders are;
  - `preview: true` turns off loading addresses.
- **Player:**
  - `webUrl` (each path part encoded) and `remoteWeb`;
  - the window button opens the page in a new tab with `noopener`.
- **Main:**
  - `importWebFolder` (`main/project/web-folder.ts`) copies a folder (links not followed, at most 2,000 files and 200 MB, safe paths), starting at `index.html` or another top-level page;
  - the new IPC call `project:importWebFolder`.
- **Editor:**
  - Insert → **Web Object**: From a Web Address (inserted at `https://example.com`, then set in the Format panel, because Electron has no `prompt`), and From a Folder…;
  - the Format panel's web section: title, shown in the slide or a new window, the address or the start page;
  - folder files are hidden from the Media panel.

## Found, and not changed

- **Opened straight from disk (`file://`), a folder page's own separate files do not load.** Chromium does not let a sandboxed page fetch other local files. The page itself, and inline script, still run. Served (an LMS, a web server, Preview), everything runs. Adding `allow-same-origin` would let the page reach the course, so the sandbox stays; pitfall #124 records the limit. The e2e therefore serves the published course from 127.0.0.1.
