## Later the same session: grow box to fit (branch `fix/grow-box-whole`)

- Luke: grow-to-fit only worked while editing the text; changing the font size on a selected box did not resize it.
- Fixed centrally (pitfall #60): every `object.update` that affects a grow-to-fit box's text, padding, autofit or width also sets the height the text needs, in the same undo step. Typing a value in a ribbon field is now one undo step, not one per keystroke.
- Test added to `e2e/text-edit.spec.ts` (fixed size does not grow; grow mode grows on font size and on narrowing; one undo restores font and height together).
- Verified: format, typecheck, lint; 308 unit tests; e2e 67 passed, 2 skipped in both built and dev renderers.
- Not verified: by hand in a visible window. The box does not shrink again when text gets smaller (same as while editing). Not applied while editing a state.

## Later again: the box shrinks too (branch `fix/fit-box-shrinks`)

- Luke: "it should shrink as well". A grow-to-fit box is now exactly as tall as its text needs after any change to its text, padding, autofit or width, and after an on-stage edit is committed. Choosing the mode fits the box immediately.
- Tests: ribbon font size up then down, narrowing then widening, and typing three lines then one on the stage.
- Verified: format, typecheck, lint; 308 unit tests; e2e 68 passed, 2 skipped in both built and dev renderers.
