## What was done

- **Courses that use the icons carry the licence (P9.8).**
  - `publishWeb` finds the library sets a course's graphics come from (`graphicLibraries`), groups included, and writes `THIRD-PARTY-NOTICES.txt` beside `index.html` with each set's notice (`noticesText`).
    - That is Lucide's whole notice, with the Feather icons' MIT notice inside it, and Open Doodles' credit when the course uses one.
    - SCORM manifests list the file, as they list every file written.
  - Publishing a course without a notice it needs fails with a message.
  - Main reads the notices from `resources/licences/` (packaged), or from the repository in development (`main/notices.ts`), for Publish and Preview.
- **A drop counts only on the targets its triggers name (P9.7).**
  - The target under a dragged object is now the topmost of the objects that its "dragged over" and "dropped on" triggers name.
  - An object drawn above a target, such as a web object's larger frame, no longer catches the drop.
  - With no such trigger, nothing shows Drag Over.
  - The Phase 9 e2e now puts the web page on top of the target again, and the drop still goes on.
- The P9.7 and P9.8 briefs, `docs/licences.md`, the skills and the handover say so.
