## What was done

- **The budget as an e2e test** (`performance.spec.ts`):
  - a 200-slide course is built from the model's factories, each slide with a title, body text, two shapes, a picture, a button with a trigger, and notes;
  - opening it must take under 3 seconds, timed from choosing the file to all 200 slides listed and the stage drawn;
  - dragging a shape and typing into a text box must keep the median frame within one 60 Hz frame and the 95th percentile within two;
  - the test checks the drag moved the shape and the words landed, so the frames measured are of real editing;
  - it prints its numbers.
- **Measured:**

  | | Windows | Linux (WSL) |
  | --- | --- | --- |
  | Open 200 slides | 624–628 ms | 475 ms |
  | Drag: median, p95 | 16.7, 16.8 ms | 16.7, 16.8 ms |
  | Typing: median, p95 | 16.7, 17.4 ms | 16.7, 16.7 ms |

- **No fixes were needed:** the editor meets the budget with room to spare. Part A is the guard that keeps it so.
- The first run found the test's own course invalid: a rounded rectangle needs a radius. Typecheck would have caught it; the test had been run before typecheck.
