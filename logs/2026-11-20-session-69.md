## What was done

- **Model, format 29:**
  - every group has `scroll: { height } | null`;
  - migration 28 → 29 sets `scroll: null` on every group, nested ones and those in question banks included;
  - legacy fixture `v28-two-slides`;
  - `ObjectChanges.scroll`.
- **Render:**
  - in a course, a scrolling group is a window (`overflow-y: auto`, a focusable named region) around its content at full height;
  - in thumbnails, the same window clips without scrolling;
  - in the editor, everything is drawn, with a dashed "Scroll window" outline;
  - the window is never taller than the group.
- **Player:**
  - Up, Down, Page Up, Page Down, Home and End scroll a focused panel instead of changing slides;
  - a redraw (a part's state changing) keeps the scroll position.
- **Editor:**
  - **Insert → Scrolling Panel** groups the selection into one, with a window half its height (at least 40), as one undo step;
  - the Format panel's new group section turns scrolling on or off and sets the window's height;
  - a `scroll` icon.
