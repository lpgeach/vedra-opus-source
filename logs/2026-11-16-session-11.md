## Done

- Model: `project.setStageSize` takes `mode: 'keep' | 'scale'` (scale resizes every frame, including group children, on slides, masters and layouts); new `project.updateTheme` for colours and fonts. Unit tests with undo in `history.test.ts`.
- Format panel (new Format tab beside Triggers and Layers): position, size, rotation; opacity, fill, stroke, shadow with theme-slot or custom colours; text autofit and padding; button corner radius; image opacity. Multi-selection edits every object in one undo step, each object keeping its own other values, and a field shows "Mixed" when values differ. Uses `editor.beginGesture`/`commitGesture` so autosave sees it.
- Design tab: Theme dialog (colours, heading/body fonts) and Stage Size dialog (scale or keep).
- Format painter (`format-painter.ts`): copies from shapes, buttons, images and text boxes onto the same kinds; single use or locked (double-click); Escape or an empty-stage click cancels; stays armed over an unsuitable target.
- Render test that a theme edit changes theme-referencing colours and fonts, leaves literals alone, and undo restores.
- Tests: `format-painter.test.ts`, the render theme test, `e2e/format-theme.spec.ts` (4 tests). Right-panel default tab changed, so one line in `e2e/editor-shell.spec.ts` now opens the Layers tab.
