## What was done

- **Windows:**
  - signing with SHA-256 only, the publisher's name, and a timestamp server, when `CSC_LINK` and `CSC_KEY_PASSWORD` are set;
  - `ELECTRON_BUILDER_OFFLINE=true` leaves the timestamp out of a test build, so nothing leaves the machine.
- **macOS:**
  - hardened runtime and our entitlements (JIT, the microphone, library validation off for the bundled tools);
  - notarised when the `APPLE_API_*` variables are set.
- **`npm run check:signing`:**
  - makes a throwaway code-signing certificate with OpenSSL;
  - packages the app with it, offline;
  - checks `Vedra Opus.exe` is signed by it;
  - deletes the certificate.
- **`docs/releasing.md`:** for Luke, what each certificate and account is, the variables, and how to check a signed build.
- **README:** the new command.

## Tests

- **Unit** (`packaging.test.ts`):
  - Windows signs with SHA-256 only, with a timestamp;
  - macOS has the hardened runtime and exactly our four entitlements;
  - the config's settings hold no certificate, password or account.
- **The signing check**, run twice on Windows. Every executable in the package was signed with the test certificate: the app's, and the bundled ffmpeg's and LibreOffice's. The output:

  ```
  Vedra Opus.exe: UnknownError, signed by CN=Vedra Opus Test Signing (sha256RSA)
  Signing works: the packaged app is signed with the certificate it was given.
  ```

  `UnknownError` is Windows not trusting a self-made certificate; the signer is what the check looks at.
