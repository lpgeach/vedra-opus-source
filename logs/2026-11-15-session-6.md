## Done

- **Brief** `docs/briefs/P2.1-application-shell.md`, written before the code. It records the layout and ten decisions. Luke had not reviewed it when the code was written; the design is cheap to change (one stylesheet, small components).
- **Layout**: top bar (save, undo, redo, project title, Story View / Slide View switch); ribbon with Home, Insert, Design, Transitions, Animations and View tabs; left panel (Slides, Media tabs); stage; bottom panel (Timeline, States, Notes tabs); right panel (Triggers, Slide Layers); status bar. The welcome screen is unchanged in behaviour.
- **Resizing and collapsing**: a divider on each panel's inner edge, operable by pointer and keyboard; collapse to a rail; View tab toggles and Reset Layout. Size rules are in the pure module `renderer/layout.ts`.
- **Persistence**: new `settings:load` / `settings:save` IPC calls; main stores `<userData>/settings.json`. Panel sizes, collapsed panels, left and bottom tabs and theme are restored after a restart.
- **Themes**: System, Light, Dark.
- **Small real behaviour**: the Slides list shows scenes and slides and selects the current slide; New Slide (ribbon and Insert menu) adds a slide after the current one; Story View lists slides as cards and opens one on double-click or Enter; the Slide Layers section lists the current slide's layers; View → Story View / Slide View menu items are live.
- Everything else in the ribbon is a disabled placeholder; panels explain what will go in them.

## Decisions

- Panels are fixed in place (no floating or re-docking).
- Settings live with the installation, not the project.
- The page applies the theme itself (`data-theme` → `color-scheme` → `light-dark()` colours). The first attempt relied on `prefers-color-scheme` following `nativeTheme.themeSource`; that did not happen in headless test runs, so it was not something to depend on. Main still sets `nativeTheme` for native menus and dialogs.
- Import Media moved to the ribbon's Insert tab, and after an import the left panel switches to its Media tab.
- The selected slide is stored as an id that may go stale (undo can remove the slide); `currentSlide()` falls back to the first slide.
