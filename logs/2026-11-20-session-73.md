## What was done

- **Model, format 33:**
  - `table` objects:
    - columns and rows sized by their shares;
    - one rich-text cell per column in every row, each with an optional fill;
    - a header row and a header column, with a header fill and text colour;
    - banded rows, border colour and width, padding;
  - validation refuses ragged rows;
  - `createTableObject`;
  - `table.ts` has pure helpers to insert or delete a row or column, change a cell, read shares, and lay the grid out;
  - `forEachRichText` visits cells, so a variable's new name reaches them;
  - migration 32 → 33 changes nothing; legacy fixture `v32-two-slides`.
- **Render:**
  - a real HTML `<table>`, fixed layout, `th` with `scope` for headers, named by its alt text;
  - each cell's text drawn as a text box's is (the new `color` option gives header text its colour);
  - `col` is a void tag in markup.
- **Editor:**
  - Insert → **Table** (3 × 4 with a header row);
  - double-click a cell to type in it: the same text editor sits over that cell alone, and the commit is one undo step;
  - the Format panel's **Table** section:
    - pick a row and column to insert above, below, left or right, delete the row or column, or set that cell's fill;
    - header row and column, with their colours;
    - bands, border, padding, column shares.
